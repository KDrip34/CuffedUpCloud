Create a board

You're the admin. The board gets one random group key (never derived from anyone's password). Each member you enroll gets their own password + TOTP secret, their own private journal key, and the group key is wrapped separately to each of them.

An update link won't work here — updates only carry new messages, not the keys you need to get in. Ask for an invite link.

Board

↩ Replying to

Messages arrive sealed. Tap to decrypt + verify; it re-seals on its own after 30–120s depending on length — tap the text to keep reading (up to a 3-minute ceiling), or Seal to close it early. Threads rank by relevance — pinned first, then recent activity; quiet threads auto-archive after about a week. Locks after 90s idle.

My Journal

Entries are encrypted with your personal journal key — not the group key — so they sync with the board but only you can decrypt them. AES-256-GCM with the entry metadata bound in as AAD, plus a SHA-256 plaintext fingerprint.

Bridge to journal.py

Re-encrypts your entries under a passphrase in the exact envelope format of the CuffedUpCloud Python journal (PBKDF2 200k → AES-256-GCM + HMAC-SHA256 + SHA-256 fingerprint). Run journal_bridge.py unpack on the result and journal.py read opens it.

Sync & settings

Your board auto-saves to this device. Add a relay below for automatic sync, or paste sync codes by hand — both carry only ciphertext.

Relay (automatic)

If this page is on https://, the relay must be https:// too — browsers block a secure page from calling a plain http:// address, so a http://192.168… relay will always show "no relay". Running the app from http://localhost:8765 is the exception, and there the app fills this in for you.

The relay stores ciphertext only — it has no key and can never read a message or journal entry. It does see metadata: board id, member names, timestamps, sizes. Run python cuffedup_server.py on any computer and point every phone at that address.

Share updates (manual)

Nothing new to share yet.

An update link carries only what's new since you last shared — a few hundred characters instead of the whole board. Your friend taps it and the messages merge on their side automatically. Everything after the # stays in the browser and is never sent to any server.

Invite a member

The right thing to send someone joining for the first time. It carries their own key envelope, everyone's public keys for signature checking, and recent history — far smaller than a full board code, and it drops them straight at the unlock screen with their name already chosen.

Full board code

For onboarding a new member or repairing a copy that's out of sync. Carries everything including member records, so it's large — paste it as text rather than a link, and the person receiving it gets asked to confirm before anyone is added to their board.

Retention

Pinned threads are never swept. Deletions travel as tombstones, so a friend's copy — and the relay — drop the ciphertext too instead of resurrecting it on the next merge. Your own messages can be deleted individually from the board.

Board

↩ Replying to

Messages arrive sealed. Tap one to decrypt + verify its signature; it re-seals after 30 seconds. Threads sort by relevance — pinned first, then recent activity; quiet threads auto-archive after about a week. The board locks after 90s idle or the moment this tab loses focus.

My Journal

Ported from the CuffedUpCloud CIA-triad journal: entries are encrypted with your personal journal key — not the group key — so they travel with the board but only you can ever decrypt them. AES-256-GCM with the entry metadata bound in as AAD (tamper the timestamp and decryption fails), plus a SHA-256 plaintext fingerprint.

Sync — no file downloads needed

Your board auto-saves to this device after every change. To share updates with friends: copy a sync code and paste it into any group chat (it's all ciphertext — the channel doesn't need to be private). When a friend sends you one, paste it below and it merges — new members, new messages, and journal entries are combined, nothing gets overwritten.

The file export still exists as a backup path — the CuffedUpCloud case study's 3-2-1 rule: keep a copy somewhere that isn't this device.

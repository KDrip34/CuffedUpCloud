Board

↩ Replying to

Messages arrive sealed. Tap to decrypt + verify; re-seals after 30s. Threads rank by relevance — pinned first, then recent activity; quiet threads auto-archive after about a week. Locks after 90s idle.

My Journal

Entries are encrypted with your personal journal key — not the group key — so they sync with the board but only you can decrypt them. AES-256-GCM with the entry metadata bound in as AAD, plus a SHA-256 plaintext fingerprint.

Bridge to journal.py

Re-encrypts your entries under a passphrase in the exact envelope format of the CuffedUpCloud Python journal (PBKDF2 200k → AES-256-GCM + HMAC-SHA256 + SHA-256 fingerprint). Run journal_bridge.py unpack on the result and journal.py read opens it.

Sync & settings

Your board auto-saves to this device. Add a relay below for automatic sync, or paste sync codes by hand — both carry only ciphertext.

Relay (automatic)

The relay stores ciphertext only — it has no key and can never read a message or journal entry. It does see metadata: board id, member names, timestamps, sizes. Run python cuffedup_server.py on any computer and point every phone at that address.

Sync codes (manual)

Retention

Pinned threads are never swept. Deletions travel as tombstones, so a friend's copy — and the relay — drop the ciphertext too instead of resurrecting it on the next merge. Your own messages can be deleted individually from the board.
